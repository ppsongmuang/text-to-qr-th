การใช้งาน

การยอมรับข้อกำหนด

การใช้เว็บไซต์หมายถึงคุณยอมรับข้อกำหนดนี้ หากไม่ยอมรับ โปรดหยุดใช้งาน เครื่องมือให้บริการโดยไม่มีค่าใช้จ่ายและอาจได้รับการปรับปรุง เปลี่ยนแปลง หรือหยุดให้บริการได้

ความรับผิดชอบของผู้ใช้

คุณต้องตรวจสอบความถูกต้องของข้อมูล ลิงก์ ผู้รับเงิน และผลการสแกนก่อนนำ QR ไปใช้จริง ห้ามใช้บริการเพื่อหลอกลวง ละเมิดสิทธิ์ เผยแพร่มัลแวร์ หรือกระทำผิดกฎหมาย

ไม่มีการรับประกัน

บริการจัดให้ “ตามสภาพ” เราไม่รับประกันว่า QR จะเข้ากันได้กับทุกอุปกรณ์หรือเหมาะกับทุกวัตถุประสงค์ งานสำคัญควรทดสอบจากไฟล์และวัสดุพิมพ์จริงก่อนเผยแพร่

บริการและลิงก์ภายนอก

เว็บไซต์อาจเชื่อมต่อไปยังแผนที่ WhatsApp Google Translate GitHub หรือบริการอื่น การใช้งานปลายทางอยู่ภายใต้ข้อกำหนดของผู้ให้บริการนั้น

ทรัพย์สินทางปัญญา

คุณยังคงรับผิดชอบและมีสิทธิ์ในข้อมูลที่นำมาสร้าง QR ตามกฎหมาย ซอร์สโค้ดของโครงการอยู่ภายใต้เงื่อนไขที่ระบุใน repository บน GitHub

การเปลี่ยนแปลงข้อกำหนด

เราอาจแก้ไขข้อกำหนดเพื่อสะท้อนฟีเจอร์หรือข้อกฎหมายใหม่ วันที่อัปเดตล่าสุดจะแสดงบนหน้านี้
