สร้าง QR Code พิกัดแผนที่ให้ไปถึงสถานที่ถูกต้อง

ชื่อสถานที่อาจซ้ำกันหรือหมุดบนแผนที่คลาดเคลื่อน การใช้พิกัดละติจูดและลองจิจูดใน QR ช่วยพาผู้ใช้ไปยังตำแหน่งที่เจาะจง เหมาะกับทางเข้าที่อยู่คนละด้านกับที่อยู่ไปรษณีย์

อ่านบทความในภาษาอื่นระบบจะเปิด Google Translate เฉพาะเมื่อคุณเลือกภาษา

หาพิกัดที่ถูกต้อง

  1. เปิดแผนที่และซูมไปยังจุดทางเข้าจริง
  2. แตะค้างหรือคลิกเพื่อปักหมุด
  3. คัดลอกตัวเลขละติจูดและลองจิจูด
  4. ตรวจว่าตัวเลขไม่มีสลับตำแหน่งกัน

สร้าง QR แผนที่

  1. เลือกเครื่องมือ “แผนที่”
  2. กรอกละติจูดและลองจิจูด
  3. เพิ่มชื่อสถานที่เพื่อให้ผู้สแกนรู้ว่าหมุดคือที่ใด
  4. สแกนและเปิดผ่านแอปแผนที่บนมือถือ
  5. ทดลองกดนำทางจากบริเวณใกล้เคียง

กรณีที่ควรใส่คำอธิบายเพิ่ม

หากอาคารมีหลายประตู ที่จอดรถอยู่คนละซอย หรือสัญญาณ GPS ไม่แม่น ควรพิมพ์ข้อความสั้นใต้ QR เช่น “ประตูฝั่งถนน A” เพื่อช่วยผู้เดินทางเมื่อเปิดแผนที่แล้ว

เช็กลิสต์ก่อนนำไปใช้

  • หมุดอยู่ที่ทางเข้าจริง
  • ละติจูดและลองจิจูดไม่สลับกัน
  • ชื่อสถานที่ชัดเจน
  • ทดสอบเส้นทางบนมือถือ
