QR GUIDE · อัปเดต 2026-11-14

วิธีทำ QR Code Wi‑Fi ให้ลูกค้าสแกนแล้วเชื่อมต่อได้

QR Code Wi‑Fi ช่วยให้แขกเชื่อมต่อเครือข่ายโดยไม่ต้องพิมพ์ชื่อและรหัสผ่านเอง โทรศัพท์ส่วนใหญ่จะอ่านชื่อเครือข่าย ประเภทความปลอดภัย และรหัสผ่านจาก QR แล้วแสดงคำขอเชื่อมต่อ

อ่านบทความในภาษาอื่นระบบจะเปิด Google Translate เฉพาะเมื่อคุณเลือกภาษา

ข้อมูลที่ต้องเตรียม

  1. ชื่อเครือข่ายหรือ SSID โดยสะกดตัวพิมพ์ใหญ่เล็กให้ตรง
  2. รหัสผ่านปัจจุบัน
  3. ประเภทความปลอดภัย ซึ่งโดยทั่วไปคือ WPA/WPA2
  4. ระบุว่าเครือข่ายซ่อนอยู่หรือไม่

วิธีสร้างและทดสอบ

  1. เลือกเครื่องมือ Wi‑Fi
  2. กรอก SSID และรหัสผ่าน
  3. เลือก WPA/WPA2, WEP หรือไม่มีรหัสผ่านให้ตรงกับเราเตอร์
  4. ดาวน์โหลด QR แล้วสแกนจากโทรศัพท์ที่ยังไม่ได้เชื่อมต่อเครือข่ายนี้
  5. ตรวจชื่อเครือข่ายในหน้าต่างยืนยันก่อนกดเชื่อมต่อ

คำแนะนำด้านความปลอดภัย

สำหรับร้านค้าควรใช้ Guest Network แยกจากเครือข่ายเครื่องคิดเงินและอุปกรณ์ภายใน เมื่อเปลี่ยนรหัสผ่านต้องสร้างและพิมพ์ QR ใหม่ อย่าวาง QR ของเครือข่ายภายในในพื้นที่สาธารณะ

เช็กลิสต์ก่อนนำไปใช้

  • ใช้ Guest Network สำหรับผู้มาเยือน
  • SSID และรหัสผ่านตรงกับเราเตอร์
  • เลือกความปลอดภัยถูกประเภท
  • สร้างใหม่ทุกครั้งที่เปลี่ยนรหัสผ่าน
